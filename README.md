# Rewire

**Daily brain games built on real neuroscience tasks.**

Rewire is a neuroplasticity trainer: three short games a day, chosen to target your weakest skill, with difficulty that adapts to keep you in the learning zone. A brain map glows as you practice and fades when you skip, a visual take on "use it or lose it."

## What's inside

**Eight games, each based on a published research task**

| Game | Skill | Based on |
|---|---|---|
| Control Tower | Working memory | N-back task |
| Night Shift | Working memory | N-back task (with tones) |
| Potion Shop | Self-control | Stroop task |
| Firefly Catch | Self-control | Go/No-Go task |
| Creature Keeper | Flexible thinking | Task switching |
| Shape Shifter Sort | Flexible thinking | Wisconsin Card Sorting Test |
| Space Dock | Spatial reasoning | Mental rotation |
| Neuron Trail | Spatial reasoning | Corsi block-tapping test |

After each game, players see their own research measure (such as switch cost or Stroop interference), the brain regions involved, a clinical connection, and an honest note on how far the benefits of practice extend.

**Puzzle Lab:** a daily 11×11 medical crossword and Term Lab, which builds medical vocabulary from Greek and Latin word parts.

**Progress tracking:** level charts for each game, a practice calendar, personal records, and a CSV export for analyzing your own data.

## What Rewire does and doesn't claim

Players get better at these tasks with practice, which is real neuroplasticity. Evidence that brain-game gains transfer to everyday thinking is limited, and Rewire makes no promise to raise IQ. It is an educational tool, not a diagnostic one. Progress is stored only in the player's own browser.

## Tech

A single HTML file (HTML, CSS and JavaScript) with no build step and no server. Hosted with GitHub Pages.
